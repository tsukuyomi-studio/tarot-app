# 🔮 星詠みタロット | スリーカード占い

過去・現在・未来を占うスリーカード・タロット占いのWebアプリです。

🔗 **公開URL**: https://tsukuyomi-studio.github.io/tarot-app/

## 概要

大アルカナ22枚の中からランダムに3枚（正位置・逆位置）を引き、
「過去」「現在」「未来」それぞれのカードが示す意味を占います。

## 特徴

- ダークで神秘的なデザイン（ナイトブルー × ゴールド）
- カードをクリックするとフリップアニメーションで結果が表示
- 外部通信・API連携なし、すべてブラウザ内のJavaScriptだけで完結
- 個人情報の入力・保存は一切なし

## 使い方

1. 「過去・現在・未来を占う」ボタンを押す
2. 裏向きに並んだ3枚のカードをそれぞれタップ/クリック
3. 3枚すべてめくると、下部に占い結果が表示される
4. 「もう一度占う」でリセットして再挑戦できる

## 技術スタック

- HTML / Vanilla JavaScript
- [Tailwind CSS](https://tailwindcss.com/)（CDN経由）

## ローカルで動かす場合

このリポジトリをクローン、または `index.html` をダウンロードして
ブラウザで直接開くだけで動作します。ビルドや依存関係のインストールは不要です。

## 注意事項

本アプリは娯楽目的のプロトタイプです。占い結果は一切の科学的根拠を保証するものではありません。
